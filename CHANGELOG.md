## [0.1.0] - 2026-06-10

### Added

- Region screenshot with frozen overlay, dim layer, and crosshair cursor (`⌃⌘⇧3`).
- Region GIF recorder with floating HUD and clipboard output (`⌃⌘⇧5`).
- Menu bar agent with Settings window (dim opacity, GIF FPS, max duration).
- `MacshotCore` + `Macshot` SwiftPM targets with CI and Homebrew release pipeline.
